# Inventaris Perpustakaan

Aplikasi web sederhana untuk mencatat buku, peminjam, dan pengembalian. Satu file (`index.html`), tanpa instalasi.

## Fitur
- Tambah, cari, dan hapus buku
- Pinjamkan buku dengan nama peminjam dan tenggat kembali
- Kembalikan buku, status terlambat otomatis
- Riwayat peminjaman
- Ekspor dan impor data (JSON)

Data disimpan di `localStorage` browser, jadi tiap perangkat punya datanya sendiri. Gunakan Ekspor data untuk cadangan atau pindah perangkat.

## Cara pakai di GitHub Pages
1. Buat repositori baru, lalu unggah `index.html` dan `README.md`.
2. Buka **Settings → Pages**.
3. Pada **Branch**, pilih `main` dan folder `/ (root)`, lalu **Save**.
4. Tunggu satu sampai dua menit. Situs aktif di `https://USERNAME.github.io/NAMA-REPO/`.
